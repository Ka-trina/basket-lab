THE SCIENCE BEHIND THE SHOT

弧線背後，是物理。

水平方向做等速度運動，垂直方向受重力影響。兩個方向疊加，就形成拋物線。

x(t) = v₀ cos(θ) · t
y(t) = h₀ + v₀ sin(θ) · t − ½gt²

v₀：初速度；θ：出手角度；h₀：出手高度；g：重力加速度。畫面會自動縮放，保留完整飛行軌跡。

怎樣才算進球？

將球視為質點：只有球向下穿越 3.05 m 的籃框平面，且水平位置距離籃框中心不超過 0.225 m，才判定進球。不模擬球體大小、碰框反彈、旋轉或空氣阻力，因此這是教學模型，不能直接預測真實投籃命中率。

角度越高，真的越容易進嗎？

角度改變會同時改變水平與垂直速度。相同初速度下，過高的角度可能讓球落在籃框前方。45° 射程最遠的結論適用於起落高度相同的情況，本模型的出手與籃框高度不同，不能直接套用。

ABOUT THIS PROJECT

從一句提示詞，到一個互動實驗室。

本作品以「將抽象物理概念變成可操作的實驗」為目標，使用 HTML、CSS 與原生 JavaScript 製作。繪圖由 Canvas 完成，不依賴外部套件或網路服務，單一檔案即可執行。

查看本作品的 AI 提示詞與實作過程

本次製作向 AI 提出的功能需求如下；這是製作規格整理，並非虛構的多輪對話紀錄。

請製作一個繁體中文的「投籃軌跡互動實驗室」，使用單一 index.html，包含完整 HTML、CSS 與原生 JavaScript，可直接放在 GitHub Pages。 功能：可調整 20–80 度出手角度、4–14 m/s 初速度與 3–9 m 籃框距離；使用標準拋體運動公式繪製預測路徑與投籃動畫；球向下穿越籃框高度時判定命中；顯示最高點、落地距離與到達籃框的高度差；提供距離挑戰、進球速度計算、實驗紀錄和 CSV 下載。 設計：米白、森林綠與橘色籃球，清楚的雙欄版面，手機可操作，控制項有標籤，結果以文字同步顯示。附物理公式、模型假設與製作說明。

實作流程：確立教學目標 → 設計版面與參數 → 實作物理公式及動畫 → 串接挑戰與紀錄 → 檢查互動功能及手機版面。

GitHub Pages 上線方式
  1. 在 GitHub 建立一個新的公開儲存庫，名稱可用 basket-lab。
  2. 使用 Add file → Upload files，將本檔案以 index.html 名稱放在儲存庫最外層，提交變更。
  3. 進入 Settings → Pages，在 Build and deployment 選擇 Deploy from a branch。
  4. 選擇 main 分支與 / (root)，按 Save；若預設分支名稱不同，選擇實際分支。
  5. 等待部署完成，開啟 Pages 顯示的網站網址，測試後將網址交給老師。
